!!!!IMPORTANT!!!!! A good Moveset contains:
-Animations
-Visual effects, prefferably from the particle emitter than the built in visuals node
-Hitboxes
-velocity for ragdolls and responsiveness
-visual confirmation with the visual blocks glow effect, make sure it's set on the humanoidrootpart so that the whole body gets affected and make sure it fades out with alt opacity
-Movesets should not feel slow and slugish or too fast and jagged
-The moves stun times shouldn't be too short (I.e less than 0.75 or in a move that is intended to be true not able to cover the time between two hits with stun)
--HOW MOVES FUNCTION IN GENERAL--
Moves do not automatically stun you so you need to manually apply it from the state block
--VELOCITY NODE--
Referred to as VELO in the json
-properties-
Force - the direction force should be applied towards. Higher number = bigger push (x,y,z)
Time - how long the force should be active for (value)
Fade - The force linearly fades to 0,0,0 over time (boolean)
Track - force direction tracks the torsos orientation for the duration of the node (boolean)
last hit - applies the velocity to whoever was hit in the last (value) seconds
ragdoll - ragdolls whoever the node is affected by for (value) seconds
True ragdoll - disables ragdoll cancel (boolean)
relative from branch - force direction is relative to the branch origin. (boolean)
-Uses and tips and tricks-
Use this for whenever you hit someone for feedback and for lunging or front dashes (track, fade, time 0.9 and z = 40-60), the time matters more than the force so keep force above 20 on all axises mostly and time low for it to be punchy and keep fade off for short bursts and track stays off too unless you want them to turn during the velocity and use relative from branch on victim branches with velocity if you want the opponent to move relative to the player
--VISUAL NODE--
You have to select a limb where the effect appears and the effect will copy the CFRAME of that limb with the rotation and position using 3D coordinates xyz to manipulate that effect around that and the center point of the effect appears at the center point of the limb you selected so be mindful of that, there are many different visual effects you need to search up on google or the jujutsu shenanigans wiki page and some things aren't mentioned on the wiki so you'll have to find those from tutorials for skill builder and it is heavily encouraged to use glow + making hit effect branch where you will put the glow and use branch target on the hitbox and make the size for the glow 0.95 for hit confirmation and alt opacity 1 this node also includes camera shakes at 3 different levels along with screen color effects and a dedicated camera effect which lets you move the camera aswell as afterimages, for more google the whole list.
--PARTICLE EMITTER NODES--
Your visual effects should primarily consist of these, just read the roblox documentation for it and that'll tell you everything you need to know. And do note for recolorable effects do not use spaces for the color3 just put it in this format: 125,125,125 no spaces
--HITBOX NODES--
Position - The hitbox's position, the origin being the player's center (x, y, z)
Rotation - the hitbox's rotation, relative to the player's orientation (x, y, z)
Size - the size of the hitbox (x, y, z)
Stun - how long the stun on hit should last for, in seconds (-1 for no stun but still mark as LAST HIT)
Stun anim - plays a generic stun animation on the hit target (boolean)
Ignore wakeup - Ignore the wakeup stun immunity (boolean, disable for accurate m1s)
Damage - how much damage should be dealt on hit
Debree - If not 0, causes destruction. the value determines debree fidelity which is 2 by default. Negative values don't spawn debree.
Attack type - used for counters to check if they can counter this type of attack (Either Melee, Bullet, Explosion, Swarm or Domain)
Blockable - the hitbox is blockable from the front (boolean)
360 block - the hitbox is blockable regardless of orientation (boolean)
Cancel enemy - cancels the hit target(s) (boolean)
Clear knockback - clears hit target(s) velocity also cancelling their ragdoll. (boolean)
Can kill - Hitbox can kill targets. if disabled the target(s) cannot receive more damage than their health. (boolean)
Hit ragdoll - The hitbox can hit ragdolls (boolean)
Hit user - the hitbox can hit the user (boolean)
Single target - the hitbox can only hit one target
Branch - proceed to a branch on hit
Branch target - forces the hit target(s) to proceed to a branch
Branch finisher - proceed to a branch if the hit was fatal
projectile tag - The name of a projectile's tag. if matched with an existing projectiles tag the hitboxes origin is set to the projectiles position.
Link user - turns the hitbox into a hurtbox for a set amount of time in seconds
--STATE NODES--
Very essential, this is required to give the move user stun and disable running and ect, cancel on end should almost always be turned on unless this is meant to be used as a debuff and if it's off it'll go off the time set for the move and the value is for certain state block statuses and doesn't affect the essentials it also features a last hit
